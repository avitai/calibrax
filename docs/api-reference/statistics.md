# calibrax.statistics

Statistical analysis tools for benchmark measurements. Provides summary
statistics, MAD-based outlier detection, percentile and bias-corrected
accelerated (BCa) bootstrap confidence intervals, classical and correlated
resample significance tests (Welch's t, Mann-Whitney U, Wilcoxon, Nadeau-Bengio
paired t-test with Student-t ROPE posteriors, and two-way repeated-measures
ANOVA + Tukey HSD), Cohen's d effect size, Benjamini-Hochberg and Foster-Stine
sequential alpha-investing FDR control, and exact non-central Student-t power
and minimum detectable effect calculations.
