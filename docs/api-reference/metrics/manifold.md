# calibrax.metrics.functional.manifold

Manifold distance metrics for structured matrix spaces. Includes the
affine-invariant and log-Euclidean distances on symmetric positive
definite (SPD) matrices, geodesic distance on Grassmann and Stiefel
manifolds, and ultrahyperbolic distance on pseudo-hyperboloids.
