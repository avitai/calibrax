# calibrax.metrics.functional.distance

Distance functions spanning a geometric hierarchy from flat spaces to
curved manifolds. Includes Euclidean, Manhattan, Chebyshev, and Minkowski
norms (flat geometry), Mahalanobis (affine), cosine and Jaccard (set/angle),
Poincare and Lorentz (hyperbolic), and Randers (asymmetric Finsler).
