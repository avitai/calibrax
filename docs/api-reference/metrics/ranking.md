# calibrax.metrics.functional.ranking

Ranking and retrieval metrics for evaluating ordered predictions. Provides
NDCG, mean average precision, precision/recall at k, mean reciprocal rank,
hit rate, catalog coverage, early-recognition BEDROC and enrichment factor,
and sequential discovery normalized AUC and shortfall.
