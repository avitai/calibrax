# calibrax.metrics.functional.divergence

Divergence functions for comparing probability distributions. Covers
KL and reverse-KL divergence, Jensen-Shannon, total variation, Hellinger,
chi-squared, Renyi, and the unified f-divergence framework. Also includes
sample-based divergences: Wasserstein-1D, sliced Wasserstein, Sinkhorn,
MMD, and Bregman divergence.
