# calibrax.metrics.functional.clustering

Clustering evaluation metrics for measuring partition quality. Covers
extrinsic measures (adjusted Rand index, NMI, AMI, V-measure) that compare
against ground-truth labels, and intrinsic measures (silhouette, Calinski-
Harabasz, Davies-Bouldin) that evaluate structure without labels.
