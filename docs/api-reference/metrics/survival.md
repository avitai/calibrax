# calibrax.metrics.functional.survival

Censored concordance and observable coverage metrics for right-, left-, and
interval-censored outcomes in survival analysis and censored assay evaluation.
Provides Harrell's concordance index, Uno's IPCW Kaplan-Meier concordance index,
left- and right-continuous reverse Kaplan-Meier censoring survival estimation,
and observable lower/upper one-sided coverage bounds.
