# calibrax.metrics.functional.calibration

Calibration and selective-inference metrics for evaluating probabilistic
predictions and conformal discovery sets. Includes Brier score, expected and
maximum calibration error, adaptive ECE, classwise ECE, reliability diagram
binning, Brier decomposition, selective-conformal FDR selection, false
discovery proportion, and empirical power.
