# calibrax.metrics.functional.calibration

Calibration metrics for evaluating probabilistic predictions. Measures how
well predicted probabilities match observed frequencies. Includes Brier
score, expected/maximum calibration error, adaptive ECE, classwise ECE,
reliability diagram binning, and Brier decomposition.
