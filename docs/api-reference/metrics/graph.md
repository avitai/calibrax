# calibrax.metrics.functional.graph

Graph distance metrics for comparing graph structures and computing
within-graph distances. Between-graph metrics (spectral distance,
approximate graph edit distance) compare two adjacency matrices.
Within-graph metrics (resistance distance, shortest path distance)
operate on a single graph.
